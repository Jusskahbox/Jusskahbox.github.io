Capstone Enhancements

For my CS 499 Computer Science Capstone, I selected Travlr Getaways, a full-stack travel application originally developed in CS 465. Rather than using three unrelated projects, I completed three cumulative enhancements to the same artifact. This approach allowed me to demonstrate how software engineering, algorithms, and database development work together within a complete application.

Enhancement One

Software Design & Engineering

Improved Travlr Getaways through stronger JWT authentication, centralized configuration, enhanced input validation, safer API error handling, and corrections to trip-management workflows.

Enhancement Two

Algorithms & Data Structures

Enhanced the administrative interface using Map-based resort indexing, Set-based unique resort generation, linear text searching, and a custom stable merge sort supporting multiple sorting criteria.

Enhancement Three

Databases

Strengthened the MongoDB and Mongoose implementation through schema validation, uniqueness constraints, compound indexes, efficient filtering and searching, sorting, pagination, and improved database error handling.
